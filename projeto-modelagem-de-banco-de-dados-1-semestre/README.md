# 🗄️ Modelagem de Banco de Dados — 1º Semestre

> Projeto acadêmico | UNICID — Análise e Desenvolvimento de Sistemas

## 📋 Descrição

Projeto de **Modelagem Lógica de Banco de Dados** desenvolvido no 1º semestre do curso de ADS. A atividade utiliza uma **analogia com projeto arquitetônico** para explicar e visualizar os conceitos de modelagem de dados, tornando abstrato o que é concreto.

## 🎯 Objetivo

Apresentar os fundamentos da modelagem de banco de dados de forma didática, relacionando:
- A planta baixa de uma edificação → ao **Diagrama Entidade-Relacionamento (ER)**
- Os cômodos e divisões → às **Entidades e Tabelas**
- As paredes e conexões → aos **Relacionamentos e Chaves Estrangeiras**

## 📚 Conceitos Abordados

- Modelo Entidade-Relacionamento (ER)
- Modelo Lógico de Banco de Dados
- Entidades, Atributos e Relacionamentos
- Chaves Primárias (PK) e Chaves Estrangeiras (FK)
- Cardinalidade (1:1, 1:N, N:M)
- Normalização de dados
- Analogia entre arquitetura e banco de dados para facilitar o aprendizado
