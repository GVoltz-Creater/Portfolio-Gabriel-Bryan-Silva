# 🧩 Engenharia de Software e IA com Bubble.io

> Projeto acadêmico | UNICID — Análise e Desenvolvimento de Sistemas

## 📋 Descrição

Desenvolvimento de uma aplicação web de gestão (gerenciador de orçamentos/férias) utilizando o **Bubble.io** e sua Inteligência Artificial como acelerador de construção, aplicando rigorosamente os fundamentos de **engenharia de software** para garantir segurança, escalabilidade e governança da solução.

## 🎯 Objetivo

Explorar o desenvolvimento *low-code* assistido por IA sem abrir mão das boas práticas de engenharia:
- Modelar a estrutura de dados da aplicação antes de construir as telas
- Definir uma estratégia de saída (exportação/portabilidade dos dados) para evitar *vendor lock-in*
- Avaliar os limites e ganhos de produtividade da IA do Bubble como acelerador de desenvolvimento
