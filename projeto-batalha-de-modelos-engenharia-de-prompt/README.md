# ⚔️ Batalha de Modelos & Engenharia de Prompt

> Projeto acadêmico | UNICID — Análise e Desenvolvimento de Sistemas

## 📋 Descrição

Projeto de análise comparativa entre diferentes modelos de linguagem (LLMs), utilizando **Engenharia de Prompt com formato XML** para avaliar precisão técnica e conformidade com instruções estritas.

## 🎯 Objetivo

Avaliar o comportamento e a precisão de diferentes LLMs diante de um conjunto rigoroso de instruções, identificando:
- Qual modelo segue instruções com mais fidelidade
- Como a formatação do prompt (especialmente em XML) influencia a resposta
- Diferenças de desempenho entre modelos para tarefas específicas

## 🛠️ Metodologia

- Criação de prompts estruturados em **formato XML**
- Aplicação dos mesmos prompts em múltiplos LLMs
- Análise qualitativa e quantitativa das respostas
- Documentação dos resultados em relatório formal

## 📚 Conceitos Abordados

- Engenharia de Prompt com estruturação XML
- Comparação entre Large Language Models (LLMs)
- Análise de conformidade e precisão de IAs
- Documentação técnica de experimentos com IA
