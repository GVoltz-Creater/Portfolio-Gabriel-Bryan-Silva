# 🏁 A Corrida do Prompt

> Projeto acadêmico | UNICID — Análise e Desenvolvimento de Sistemas

## 📋 Descrição

Atividade prática de Engenharia de Prompt com o objetivo de chegar a um resultado esperado em **exatamente 5 interações** com um modelo de linguagem (LLM). O desafio consiste em planejar e refinar os prompts de forma estratégica, aprendendo a comunicar intenções com precisão e eficiência para IAs generativas.

## 🎯 Objetivo

Desenvolver a habilidade de engenharia de prompt ao impor uma restrição rígida de tentativas, forçando o estudante a:
- Pensar antes de escrever o prompt
- Estruturar a instrução de forma clara e objetiva
- Analisar e iterar sobre o resultado de cada interação
- Alcançar o objetivo dentro do limite de 5 rodadas

## 📂 Conteúdo

O repositório contém evidências fotográficas e screenshots registrando cada etapa da atividade, incluindo os prompts utilizados e as respostas obtidas da IA.

## 🛠️ Ferramentas Utilizadas

- Modelo de linguagem (LLM) de IA generativa
- Engenharia de Prompt como método de trabalho

## 📚 Aprendizados

- Comunicação clara e estruturada com IAs
- Iteração controlada e análise crítica de resultados
- Técnicas de refinamento progressivo de prompts
